by the current code, constructor signatures, common methods, and examples.

## How to read the parameter tables

Each type page lists the current source signature. Parameters may come from the control itself, or be passed to the generic Control via
**base. The Control page lists the size, visibility, layout, animation,
focus, and transform parameters.

A parameter being "accepted by the constructor" does not necessarily mean the feature is implemented. For Flet compatibility parameters, the API
page notes when non-default values are unsupported; for the full differences see
[Control parameter comparison](../control-parameters-comparison.md).

## Updating from source

The API pages in the repository are generated by a tool:

~~~powershell
python tools/build_saturn_docs.py
~~~

This generates docs/api/ from saturn.__all__, runtime signatures, parameter descriptions, and examples. Hand-written
chapters stay independent and are not overwritten by this command.

## Key points of this chapter

Read the concept chapters by task first, then jump to API pages by symbol; when in doubt about cross-framework compatibility, check the difference tables
and run the code locally. The source code of the current version is the final behavioral authority.
